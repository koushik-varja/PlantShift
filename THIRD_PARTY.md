# Third-party packages

PlantShift's application code is original. It uses public open-source libraries through documented APIs. Exact transitive licenses should be re-checked from the lock/environment used for a release.

| Package | Purpose | Common license |
|---|---|---|
| FastAPI | HTTP API | MIT |
| Pydantic | validation | MIT |
| SQLAlchemy | persistence | MIT |
| Alembic | migrations | MIT |
| NumPy | numerical operations | BSD-3-Clause |
| pandas | analysis / ML feature preparation | BSD-3-Clause |
| scikit-learn | ML | BSD-3-Clause |
| paho-mqtt | MQTT client | EPL-2.0 / EDL-1.0 |
| PostgreSQL | database | PostgreSQL License |
| TimescaleDB | time-series extension | Apache-2.0 core components; verify image/component terms |
| Eclipse Mosquitto | MQTT broker | EPL-2.0 / EDL-1.0 |
| React | UI | MIT |
| Vite | frontend tooling | MIT |
| Recharts | charts | MIT |
| ESLint / typescript-eslint | frontend static analysis tooling | MIT |

No vendor UI, proprietary consulting framework, or public digital-twin repository is copied into PlantShift.
